# Zenith Yacht Charters redesign

Public pitch: https://zenith-yacht-pitch.antonielewis.chatgpt.site

This repository contains the complete static website. The homepage is `index.html`; keep the regional folders and `assets` beside it. Serve the repository root with any static web host or GitHub Pages.

Built from Zenith's public website on 7 October 2026: 239 pages and 103 yacht listings across Singapore, Malaysia and Thailand. Original logo, branding, specifications, published prices and policies are preserved. Source pricing is not live availability; expired rates are flagged.

The enquiry forms prepare WhatsApp or email messages. They do not automatically send messages or confirm bookings. The pitch remains noindex until an approved production migration.
